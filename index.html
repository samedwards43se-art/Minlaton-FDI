GFDI = 2·exp(−23.6 + 5.01·ln C + 0.0281·T − 0.226·√RH + 0.633·√V), C = 100. Categories shown are the standard McArthur grassland classes. The SA Grain Harvesting Code sets its own harvest thresholds and wind inputs, so check the current Code and official Bureau of Meteorology and CFS sources before making harvest decisions.
